      ลำดับไอคอนชื่อเมนู / URLแสดงให้ต่อท้ายลิงก์แสดง

      ค่าตั้งระบบ — ส่งออก / นำเข้าเป็นไฟล์เดียว

      ใช้เมื่อย้ายไฟล์ Google Sheets ไปไว้บัญชี Google อื่น — เฉพาะ Superadmin

      ทำไมต้องมี: เมื่อคัดลอกไฟล์ Google Sheets ไปบัญชีอื่น ชีตผู้ใช้/Log/ข้อมูลจะติดไปด้วย แต่ค่าตั้งระบบใน Apps Script (Script Properties) ไม่ติดไป ทำให้ล็อกอินไม่ได้ (กุญแจเข้ารหัสรหัสผ่านเปลี่ยน) และลิงก์ระบบอื่น/แผนงานที่ไม่รวมคำนวณกลับเป็นค่าเริ่มต้น — ให้ส่งออกจากระบบเดิม แล้วนำเข้าที่ระบบใหม่

      1ส่งออกจากระบบนี้

      ไฟล์ .json ประกอบด้วย กุญแจเข้ารหัสรหัสผ่าน, ลิงก์ระบบอื่น และแผนงานที่ไม่รวมคำนวณ

      ⚠️ ไฟล์นี้มีกุญแจเข้ารหัสรหัสผ่าน เก็บไว้ในที่ปลอดภัย และลบทิ้งเมื่อย้ายระบบเสร็จ

      2นำเข้าที่ระบบใหม่

      เลือกไฟล์ที่ส่งออกจากระบบเดิม ระบบจะแสดงรายการที่จะเปลี่ยนก่อนยืนยัน

      หลังนำเข้า ผู้ใช้คนอื่นใช้รหัสผ่านจากระบบเดิม ได้ทันที ส่วนคุณใช้รหัสผ่านปัจจุบันต่อได้ (เช่น รหัสที่เพิ่งตั้งหลัง Run resetAdminPasswordFromEditor)

      Site Map · แผนผังระบบโครงสร้างเมนูและฟังก์ชันของระบบสรุปผลการใช้จ่ายงบประมาณ

      คู่มือการใช้งานระบบระบบสรุปผลการใช้จ่ายงบประมาณ สช.

      คู่มือการใช้งานระบบสรุปผลการใช้จ่ายงบประมาณ

      สำนักงานคณะกรรมการสุขภาพแห่งชาติ (สช.)

      ฉบับปรับปรุง: ตุลาคม 2569เรียงหัวข้อตาม Site Map ของระบบ
      คู่มือนี้แบ่งหัวข้อตามโครงสร้างเมนูใน Site Map — คลิกหัวข้อใน สารบัญ เพื่อไปยังเรื่องที่ต้องการ หรือกดปุ่ม ดาวน์โหลด PDF เพื่อเก็บไว้อ่านหรือพิมพ์
      อ่านภาพประกอบ: เส้นชี้สีแดง ลากจากคำอธิบายรอบภาพไปยังจุดสีแดงบนปุ่มหรือช่องที่กล่าวถึง ส่วนปีกกาสีแดงหมายถึงทั้งกลุ่ม เช่น ลิงก์ไปยังระบบอื่นทั้ง 5 ระบบ

      สารบัญ

      0รู้จักระบบ

      ระบบสรุปผลการใช้จ่ายงบประมาณ แสดงภาพรวมการเบิกจ่ายงบประมาณ เทียบกับแผนการใช้จ่าย จำแนกตามแหล่งงบประมาณ หน่วยงาน แผนงาน และโครงการ โดยใช้ข้อมูลจาก ระบบ e-Office และ ระบบ ERP ที่นำเข้าไว้ใน Google Sheets

      0.1ผู้ใช้งานและสิทธิ์

      ประเภทผู้ใช้สิ่งที่ทำได้
      ผู้เยี่ยมชม
      (ไม่เข้าสู่ระบบ)      		ดู Dashboard ทุกมุมมอง, พิมพ์ข้อมูล, ส่งออก Excel, Site Map และคู่มือ (ปุ่ม ช่วยเหลือ)
      Userเหมือนผู้เยี่ยมชม + เปลี่ยนรหัสผ่าน และสิทธิ์เพิ่มเติมที่ได้รับเป็นรายคน เช่น ดาวน์โหลดชุดข้อมูลต้นฉบับ, ยืนยันความถูกต้องของข้อมูล, บันทึกผลดำเนินงาน, จัดการผู้ใช้งาน, เรียกดู Log
      Adminทุกสิทธิ์ข้างต้น + ระบบจัดการหลังบ้าน (ผู้ใช้งานและสิทธิ์, Log) — ยกเว้นการลบ Log; เมนู จัดการข้อมูล และ ตั้งค่าการคำนวณ ใช้ได้เฉพาะคนที่ Superadmin เปิดสิทธิ์ให้ (แยกกันรายสิทธิ์)
      Superadminทุกสิทธิ์ รวมถึงลบ Log, จัดการข้อมูล, ตั้งค่าการคำนวณ และจัดการบัญชี Admin / Superadmin

      0.2ระบบที่เชื่อมโยงกัน

      ระบบนี้คือหมายเลข 1 ใน Site Map และมีลิงก์ไปยังระบบอื่นตามที่ตั้งค่าไว้ เริ่มจากหมายเลข 2 (ค่าเริ่มต้น 7 ระบบ ดูหัวข้อ 4)

      1Dashboard · หน้าจอหลัก

      1.1ส่วนหัวของหน้าจอ

      • ป้ายปีงบประมาณ (สีทอง) — ปีงบประมาณของข้อมูลชุดที่แสดงอยู่
      • ข้อมูลระบบ ณ วันที่ — วันเวลาที่ดึงข้อมูลจากระบบต้นทาง ใช้ตรวจสอบว่าเป็นข้อมูลชุดล่าสุดหรือไม่
      • ปุ่ม พิมพ์ข้อมูล ส่งออก Excel และ เข้าสู่ระบบ (หรือชื่อผู้ใช้ เมื่อเข้าสู่ระบบแล้ว)

      1.2แถบสรุปภาพรวม (KPI)

      • งบประมาณรวมทั้งสิ้น, เบิกจ่ายจริง (รวมผูกพัน) และ คงเหลือสุทธิ
      • ร้อยละเบิกจ่าย (รวมผูกพัน) พร้อมแถบความคืบหน้า แยกสี เบิกจ่ายจริง / งบผูกพัน / คงเหลือ
      • เส้นสีเหลืองบนแถบ = %แผนที่ตั้งไว้ ของเดือนปัจจุบัน และข้อความบอกว่าผลสูงหรือต่ำกว่าแผนเท่าใด

      1.3การอ่านสีและสัญลักษณ์

      สัญลักษณ์ความหมาย
      เป็นไปตามแผน — ร้อยละเบิกจ่ายเท่ากับหรือมากกว่า %แผนที่ตั้งไว้
      น้อยกว่าแผน — ร้อยละเบิกจ่ายต่ำกว่า %แผนที่ตั้งไว้
      %แผนที่ตั้งไว้ ของเดือนปัจจุบัน (เส้นตั้งบนแถบ)
      %ดำเนินงาน (แสดงในมุมมองรายแผนงานและรายโครงการ)
      ตรายืนยันสีเขียว — ข้อมูลส่วนนั้นได้รับการยืนยันความถูกต้องแล้ว (ชี้เมาส์เพื่อดูผู้ยืนยันและเวลา)
      ตรายืนยันสีแดง — รอการยืนยันความถูกต้อง
      ชี้เมาส์ที่แถบหรือรายการ เพื่อดูยอดเงิน (งบประมาณ, เบิกจ่ายจริง, ผูกพัน, คงเหลือ) ของรายการนั้น

      2มุมมองข้อมูล

      เลือกมุมมองจากแถบเมนูด้านซ้าย (บนมือถืออยู่ด้านบน) ทุกมุมมองมีองค์ประกอบเหมือนกัน 3 ส่วน:

      • สัดส่วนการจัดสรรงบประมาณ — กราฟวงแหวนและรายการ % ของงบประมาณ
      • ประสิทธิภาพการเบิกจ่ายเทียบกับแผน (%) — แถบร้อยละเบิกจ่ายของแต่ละรายการ เทียบเส้น %แผน
      • ตารางสรุป — ค้นหาด้วยชื่อหรือรหัสได้ที่ช่อง ค้นหาชื่อหรือรหัส
      ดูรายการย่อย: คลิกแถวในกราฟแท่งหรือในตาราง ระบบจะเปิดแผงรายละเอียดด้านขวา แสดงรายการระดับถัดไปพร้อมยอดรวม ในแผงนี้คลิกรหัสหรือแถวเพื่อเจาะดูระดับถัดไปได้อีก (แผนงาน → โครงการ → กิจกรรม) เส้นทางที่กำลังดูแสดงอยู่ด้านบน และกดปุ่ม ‹ ย้อนกลับ เพื่อกลับไประดับก่อนหน้า

      2.1ภาพรวมงบประมาณ

      แสดงงบประมาณตาม แหล่งงบประมาณ 2 แหล่ง คือ งบ สช. และ งบโครงการพิเศษ (แผนงาน P04) — คลิกแหล่งงบเพื่อดู รายการแผนงาน แต่ละแหล่งงบ

      2.2รายหน่วยงาน

      แสดงงบประมาณและการเบิกจ่ายของแต่ละสำนัก/หน่วยงาน — คลิกหน่วยงานเพื่อดู รายการโครงการ แต่ละหน่วยงาน

      2.3รายแผนงาน

      แสดงข้อมูลแยกตามแผนงาน (เช่น 70P01) พร้อม %ดำเนินงาน — คลิกแผนงานเพื่อดู รายการโครงการ แต่ละแผนงาน

      2.4รายโครงการ

      แสดงข้อมูลแยกตามโครงการ (เช่น 70P01A) พร้อม %ดำเนินงาน — คลิกโครงการเพื่อดู รายการกิจกรรม แต่ละโครงการ

      3ส่งออกรายงาน

      3.1พิมพ์ข้อมูล (Print)

      1. กดปุ่ม พิมพ์ข้อมูล มุมขวาบน
      2. ระบบสร้างรายงานครบ 4 มุมมอง (แหล่งงบ, หน่วยงาน, แผนงาน, โครงการ) ขนาด A4 แนวนอน พร้อมตรายืนยันความถูกต้อง
      3. เลือกเครื่องพิมพ์ หรือเลือกปลายทาง บันทึกเป็น PDF เพื่อเก็บเป็นไฟล์
      ในหน้าต่างพิมพ์ ให้เปิดตัวเลือก กราฟิกพื้นหลัง (Background graphics) เพื่อให้สีแสดงครบ

      3.2ส่งออก Excel

      กดปุ่ม ส่งออก Excel ระบบจะดาวน์โหลดไฟล์ .xlsx ที่มีชีตแยกตามมุมมอง จัดรูปแบบตัวเลข/ร้อยละ และใช้สีตามเกณฑ์เดียวกับหน้าจอ

      4ลิงก์ระบบอื่น

      อยู่ในแถบเมนูด้านซ้ายใต้มุมมองข้อมูล ทุกลิงก์เปิดใน แท็บใหม่ (หน้า Dashboard ยังเปิดอยู่)

      บนมือถือ / แท็บเล็ต: ลิงก์ระบบอื่นย้ายไปอยู่ในเมนู ☰ มุมขวาบนของหน้าจอ กดเพื่อเปิดรายการลิงก์ แล้วกดลิงก์ที่ต้องการ
      หมายเลขเมนู (ค่าเริ่มต้น)ใช้สำหรับ
      2ตรวจสอบงบประมาณระบบตรวจสอบงบประมาณ — แสดงเฉพาะเมื่อเข้าสู่ระบบแล้ว และส่งชื่อ-สกุลของผู้ใช้ไปยังระบบปลายทางให้อัตโนมัติ
      3เอกสารใช้จ่ายงบค้นหา/ตรวจสอบเอกสารการใช้จ่ายงบประมาณ
      4งบการเงินรายงานงบการเงิน
      5สรุปผลใช้จ่ายงบ ปี 69Dashboard สรุปผลการใช้จ่ายงบประมาณของปีงบประมาณ 2569
      6แบ่งปันความรู้แหล่งแบ่งปันความรู้และเอกสารที่เป็นประโยชน์
      7คู่มือใช้ระบบ ERPคู่มือและวิธีใช้งานระบบ ERP
      8ERP Progressติดตามความคืบหน้าการดำเนินงานระบบ ERP
      รายการลิงก์ ลำดับ ไอคอน และการแสดงผล Superadmin ปรับได้เองที่ระบบจัดการหลังบ้าน › ลิงก์ระบบอื่น (หัวข้อ 6.5) — หมายเลขใน Site Map จะเรียงตามลำดับเมนูที่ตั้งไว้

      5เข้าสู่ระบบ (Login)

      5.1เข้าสู่ระบบ / ออกจากระบบ

      1. กดปุ่ม เข้าสู่ระบบ มุมขวาบน
      2. กรอก ชื่อผู้ใช้ (Username) และ รหัสผ่าน (Password) แล้วกด เข้าสู่ระบบ
      3. เข้าสู่ระบบครั้งแรกด้วยรหัสผ่านชั่วคราว ระบบจะให้ตั้งรหัสผ่านใหม่ก่อนใช้งาน
      4. ออกจากระบบ: คลิกชื่อผู้ใช้มุมขวาบน › ออกจากระบบ › ยืนยัน
      ใส่รหัสผ่านผิดเกิน 5 ครั้ง บัญชีจะถูกล็อกชั่วคราว 15 นาที · หากไม่ได้ใช้งานนาน 60 นาที ระบบจะออกจากระบบให้อัตโนมัติ

      5.2ลืมรหัสผ่าน (OTP)

      1. ที่หน้าเข้าสู่ระบบ กด ลืมรหัสผ่าน?
      2. กรอกชื่อผู้ใช้ แล้วกด ส่งรหัส OTP — ระบบส่งรหัส 6 หลักไปทางอีเมลที่ท่านลงทะเบียนไว้ (อายุ 15 นาที)
      3. กรอกรหัส OTP และตั้งรหัสผ่านใหม่
      ไม่ได้รับอีเมล หรือยังไม่ได้ลงทะเบียนอีเมล — ติดต่อผู้ดูแลระบบที่แสดงในหน้าเข้าสู่ระบบ เพื่อรีเซ็ตรหัสผ่านให้

      5.3เปลี่ยนรหัสผ่าน

      คลิกชื่อผู้ใช้ › เปลี่ยนรหัสผ่าน › กรอกรหัสผ่านปัจจุบันและรหัสผ่านใหม่ 2 ครั้ง

      • อย่างน้อย 8 ตัวอักษร มีทั้งตัวอักษรภาษาอังกฤษและตัวเลข และต้องไม่มีชื่อผู้ใช้อยู่ในรหัสผ่าน
      • เปลี่ยนแล้ว อุปกรณ์อื่นที่เข้าสู่ระบบด้วยบัญชีนี้จะถูกออกจากระบบ

      5.4Site Map

      คลิกชื่อผู้ใช้ › Site Map (ถ้ายังไม่เข้าสู่ระบบ ใช้ปุ่ม ช่วยเหลือ › Site Map) เพื่อดูแผนผังเมนูทั้งหมดของระบบ ใช้ปุ่ม ขนาดจริง / พอดีหน้าจอ เพื่อย่อขยาย และ ดาวน์โหลดรูปภาพ เพื่อบันทึกเป็นไฟล์ PNG

      5.5ยืนยันความถูกต้องของข้อมูล

      สำหรับผู้ที่ได้รับสิทธิ์ ยืนยันความถูกต้องของข้อมูล

      1. คลิกตราสีแดงหน้าหัวข้อที่ต้องการ (การ์ด KPI, กราฟ, ตาราง หรือรหัสรายการ)
      2. ใส่หมายเหตุ (ถ้ามี) แล้วกด ยืนยันว่าถูกต้อง — ตราจะเปลี่ยนเป็นสีเขียว
      3. ยกเลิกการยืนยัน: คลิกตราสีเขียว ระบุเหตุผล แล้วกด ยกเลิกการยืนยัน
      ยืนยันครั้งเดียว ใช้ได้ทุกจุด: รหัสรายการเดียวกัน (เช่น โครงการ 70P01A) ที่แสดงอยู่หลายมุมมอง เมื่อยืนยันจุดใดจุดหนึ่งแล้ว ตราของรหัสนั้นในมุมมองอื่น (รายหน่วยงาน, รายแผนงาน, รายโครงการ) จะเป็นสีเขียวทันที ไม่ต้องยืนยันซ้ำ — ใช้กับรหัสที่ตรงกันทุกตัวอักษรเท่านั้น การยืนยันโครงการ 70P01A จึงไม่ทำให้แผนงาน 70P01 หรือโครงการ 70P01B ถูกยืนยันไปด้วย
      ใช้ผลยืนยันเดิมเมื่อยอดไม่เปลี่ยน: เมื่อนำเข้าข้อมูลชุดใหม่ (วันที่ "ข้อมูลระบบ ณ วันที่" เปลี่ยน) ระบบเทียบตัวเลขที่แต่ละส่วนแสดงกับตอนที่ยืนยันไว้
      • ยอดเท่าเดิมทุกตัว — ตรายังเป็นสีเขียว โดยใช้ผลยืนยันเดิม เมื่อชี้ที่ตราจะเห็นข้อความ "ใช้ผลเดิม" พร้อมวันที่ของข้อมูลชุดที่ยืนยันไว้ ผู้ยืนยัน และเวลา
      • ยอดเปลี่ยนแม้ตัวเดียว — ตรากลับเป็นสีแดง (รอการยืนยัน) เฉพาะส่วนที่เปลี่ยน ส่วนอื่นยังเป็นสีเขียว
      • ตัวเลขที่นำมาเทียบคือที่ส่วนนั้นแสดงจริง รวม %แผนที่ตั้งไว้ (เมื่อข้ามเดือน %แผนมักเปลี่ยน ส่วนที่แสดง %แผนจึงต้องยืนยันใหม่) แต่ไม่รวม %ดำเนินงาน ซึ่งมีประวัติผู้บันทึกแยกต่างหาก
      • ถ้าข้อมูลชุดเดิม (วันที่เดิม) ถูกอัปโหลดใหม่และยอดเปลี่ยนไปจากตอนที่ยืนยัน ตราจะกลับเป็นสีแดงเช่นกัน

      5.6บันทึกผลดำเนินงาน (%ดำเนินงาน)

      สำหรับผู้ที่ได้รับสิทธิ์ บันทึกผลดำเนินงาน (Admin / Superadmin มีสิทธิ์นี้อยู่แล้ว) บันทึกได้เฉพาะระดับกิจกรรม

      1. เลือกมุมมอง รายโครงการ แล้วคลิกโครงการที่ต้องการ ระบบจะเปิดแผงรายการกิจกรรม
      2. คลิกไอคอนดินสอท้ายช่อง %ดำเนินงาน ของกิจกรรมนั้น
      3. กรอกตัวเลข 0 – 100 แล้วกด ✓ หรือ Enter เพื่อบันทึก (กด ✕ หรือ Esc เพื่อยกเลิก)
      ระดับค่าที่บันทึกในชีต "ผลดำเนินงาน"
      กิจกรรมค่าที่ผู้ใช้กรอก
      โครงการผลรวมของ (%ดำเนินงานกิจกรรม × %ค่าน้ำหนักกิจกรรม ÷ 100) ทุกกิจกรรมภายใต้โครงการ — กิจกรรมที่ยังไม่กรอกนับเป็น 0
      แผนงานผลรวมของ (%ดำเนินงานโครงการ × %ค่าน้ำหนักโครงการ ÷ 100) ทุกโครงการภายใต้แผนงาน — โครงการที่ยังไม่มีผลจะถูกเติมเป็น 0
      ตัวอย่าง: กิจกรรม 70P01A01 = 40% (ค่าน้ำหนัก 13.58) และ 70P01A02 = 80% (ค่าน้ำหนัก 3.80) → โครงการ 70P01A = 40×13.58÷100 + 80×3.80÷100 = 8.47% → แผนงาน 70P01 ได้จากโครงการนี้ 8.47×78.74÷100 = 6.67% (บวกกับผลของโครงการอื่นในแผนงาน)
      ระบบคำนวณระดับโครงการและแผนงานให้อัตโนมัติทุกครั้งที่บันทึก แล้วโหลด Dashboard ใหม่ทันที — ค่า %ดำเนินงานของกิจกรรมที่บันทึกผ่านระบบจะมีเส้นประใต้ตัวเลข เมื่อชี้เมาส์ (หรือแตะบนมือถือ) จะแสดง "บันทึกโดย ชื่อผู้บันทึก" พร้อมวันเวลาที่บันทึกล่าสุด และทุกการบันทึกจะถูกเก็บใน Log (กิจกรรม "บันทึก %ดำเนินงาน") และในชีตระบบ SYS_Perf

      5.7คู่มือการใช้งานระบบ

      คลิกชื่อผู้ใช้ › คู่มือการใช้งานระบบ (ถ้ายังไม่เข้าสู่ระบบ ใช้ปุ่ม ช่วยเหลือ › คู่มือการใช้งานระบบ) เพื่อเปิดคู่มือนี้ — กด ดาวน์โหลด PDF แล้วเลือกปลายทาง บันทึกเป็น PDF

      6ระบบจัดการหลังบ้าน

      คลิกชื่อผู้ใช้ › ระบบจัดการหลังบ้าน (แสดงเฉพาะผู้มีสิทธิ์) — แท็บที่เห็นขึ้นกับสิทธิ์ของแต่ละบัญชี กด กลับสู่ Dashboard เพื่อออกจากหลังบ้าน

      6.1ผู้ใช้งานและสิทธิ์

      • นำเข้าผู้ใช้งานทั่วไป — เพิ่มผู้ใช้บทบาท User หลายคนจากไฟล์ Excel (ดูด้านล่าง)
      • เพิ่มผู้ใช้ — กด + เพิ่มผู้ใช้ กรอกชื่อผู้ใช้ ชื่อ-สกุล อีเมล หน่วยงาน บทบาท วันหมดอายุ (ถ้ามี) เลือกสิทธิ์ และวิธีตั้งรหัสผ่านเริ่มต้น (สุ่มหรือกำหนดเอง, ส่งอีเมลแจ้งผู้ใช้ได้)
      • แก้ไข — กดไอคอนดินสอ เพื่อแก้ข้อมูล บทบาท สถานะ หรือสิทธิ์
      • ลบทิ้ง — กดไอคอนถังขยะ แล้วยืนยัน (ลบถาวร)
      • รีเซ็ตรหัสผ่าน — กดไอคอนกุญแจ ระบบออกรหัสผ่านชั่วคราว และปลดล็อกบัญชีให้ด้วย
      • ค้นหา และกรองตามบทบาท / สถานะ ได้ที่ด้านบนตาราง
      สิทธิ์ที่กำหนดได้รายละเอียด
      ดาวน์โหลดชุดข้อมูลต้นฉบับเข้าถึงลิงก์ไฟล์ Google Sheets ที่ใช้ประมวลผล
      ยืนยันความถูกต้องของข้อมูลยืนยัน / ยกเลิกการยืนยันข้อมูลแต่ละส่วนบน Dashboard
      บันทึกผลดำเนินงานแก้ไข %ดำเนินงานระดับกิจกรรม (Admin / Superadmin มีสิทธิ์นี้อยู่แล้ว)
      จัดการผู้ใช้งาน และสิทธิ์จัดการได้เฉพาะบัญชีที่บทบาทไม่สูงกว่าตนเอง
      เรียกดู Log การใช้งานระบบค้นหาและส่งออก Log (การลบ Log ทำได้เฉพาะ Superadmin)
      จัดการข้อมูลให้ได้เฉพาะบทบาท Admin เป็นรายคน โดย Superadmin เท่านั้น
      ตั้งค่าการคำนวณให้ได้เฉพาะบทบาท Admin เป็นรายคน โดย Superadmin เท่านั้น (ดูหัวข้อ 6.4)

      นำเข้าผู้ใช้งานทั่วไปจากไฟล์ Excel

      ใช้เพิ่มผู้ใช้บทบาท User ครั้งละหลายคน (สูงสุด 300 คนต่อไฟล์)

      1. กด นำเข้าผู้ใช้งานทั่วไป แล้วเลือกไฟล์ .xlsx, .xls หรือ .csv
      2. ระบบแสดงรายชื่อพร้อมผลตรวจรายแถว — แถวที่ชื่อผู้ใช้/อีเมลซ้ำกับบัญชีเดิม ซ้ำกันเองในไฟล์ หรือข้อมูลไม่ถูกต้อง จะถูกข้ามพร้อมแจ้งเหตุผล
      3. เลือกสิทธิ์เพิ่มเติมที่จะให้ทุกบัญชี (ไม่บังคับ) แล้วกด นำเข้า … บัญชี
      คอลัมน์ในไฟล์ (หัวตาราง)รายละเอียด
      ลำดับไม่บังคับ
      ชื่อหน่วยงานเช่น สำนักนโยบายสาธารณะภาคเหนือ (สช.น.)
      ชื่อ-สกุลบังคับ
      อีเมลใช้รับรหัส OTP เมื่อลืมรหัสผ่าน (ต้องไม่ซ้ำกับบัญชีอื่น)
      ชื่อผู้ใช้ (Username)บังคับ — a-z, 0-9, จุด, ขีด หรือขีดล่าง ยาว 3–30 ตัวอักษร
      รหัสผ่าน (เข้าครั้งแรก)อย่างน้อย 8 ตัวอักษร มีทั้งตัวอักษรภาษาอังกฤษและตัวเลข — เว้นว่าง = ระบบสุ่มให้และแสดงหลังนำเข้า (ครั้งเดียว)
      ทุกบัญชีที่นำเข้าต้องเปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก ระบบจึงยอมรับรหัสผ่านเริ่มต้นที่มีชื่อผู้ใช้อยู่ด้วยได้ (เช่น wunvisa1234) แต่รหัสผ่านใหม่ที่ผู้ใช้ตั้งเองต้องผ่านเงื่อนไขครบทุกข้อ — การนำเข้าบันทึกลง Log ทุกครั้ง

      6.2Log การใช้งาน

      • ค้นหา (Search) — กรองตามช่วงวันที่ ผู้ใช้ กิจกรรม ผลลัพธ์ และคำค้น แล้วกดค้นหา
      • ส่งออก CSV / ส่งออก Excel — ส่งออกเฉพาะรายการที่ตรงกับตัวกรองปัจจุบัน
      • ล้าง Log (เฉพาะ Superadmin) — ลบ Log ที่ตรงกับตัวกรองปัจจุบันอย่างถาวร ควรส่งออกเก็บไว้ก่อน

      6.3จัดการข้อมูล

      ใช้นำเข้าข้อมูลชุดใหม่จากระบบต้นทางเข้าสู่ Google Sheets (เฉพาะ Superadmin และ Admin ที่ได้รับสิทธิ์)

      • ดาวน์โหลดสำรอง — ติ๊กเลือกชีต แล้วกดดาวน์โหลดเป็นไฟล์ Excel
      • ล้างข้อมูล — ติ๊กเลือกชีต แล้วกดล้าง (ยืนยัน 2 ครั้ง) ระบบจะดาวน์โหลดไฟล์สำรองให้อัตโนมัติก่อนล้าง
      • สำรองทีละชีต — กดปุ่ม สำรอง ท้ายแถวของชีตนั้น
      • อัปโหลดไฟล์ใหม่ทีละชีต — ดูขั้นตอนด้านล่าง
      1. กด อัปโหลดไฟล์ใหม่ ท้ายแถวของชีตที่ต้องการ แล้วเลือกไฟล์ .xlsx, .xls หรือ .csv
      2. ถ้าไฟล์มีหลายแผ่นงาน ให้เลือกแผ่นงานที่จะใช้ ตรวจตัวอย่างข้อมูลและจำนวนแถว
      3. ยืนยัน 2 ครั้ง — ระบบดาวน์โหลดไฟล์สำรองข้อมูลเดิมลงเครื่อง แล้วแทนที่ข้อมูลในชีต
      4. Dashboard โหลดข้อมูลชุดใหม่ทันที — ส่วนที่ยอดไม่เปลี่ยนใช้ผลยืนยันเดิม ส่วนที่ยอดเปลี่ยนกลับเป็น "รอการยืนยัน" (ดูหัวข้อ 5.5)
      อัปโหลดชีต "ผลดำเนินงาน": ระบบคำนวณ %ดำเนินงานของโครงการและแผนงานใหม่ทั้งหมดจากค่ากิจกรรม × ค่าน้ำหนัก (สูตรเดียวกับหัวข้อ 5.6) ถ้าค่าในไฟล์ไม่ตรงกับที่คำนวณได้ ระบบใช้ค่าที่คำนวณและแสดงรายการที่แก้ให้ทราบ — กิจกรรมที่ค่าเปลี่ยนจากการอัปโหลดจะแสดง "อัปโหลดไฟล์โดย …" เมื่อชี้ที่ %ดำเนินงาน
      ไฟล์ที่อัปโหลดต้องมีโครงสร้างคอลัมน์เหมือนรายงานต้นทางเดิม (RLB-002 / RLB-003 / แผนการใช้จ่าย / ผลดำเนินงาน) และควรมีปีงบประมาณ เช่น "ปีงบประมาณ 2570" ที่เซลล์ A1 · การอัปโหลดนำเข้าเฉพาะค่า ไม่นำสีหรือรูปแบบมาด้วย

      6.4ตั้งค่าการคำนวณ

      ใช้เลือกแผนงานที่ไม่ต้องการนำมารวมคำนวณ %เบิกจ่าย เช่น แผนงานที่ไม่อยู่ในความสนใจของผู้บริหาร — ใช้ได้เฉพาะผู้มีสิทธิ์ ตั้งค่าการคำนวณ (Superadmin ทุกคน / Admin ที่ Superadmin ติ๊กเปิดสิทธิ์ให้ในหน้าแก้ไขผู้ใช้)

      1. เปิดแท็บ ตั้งค่าการคำนวณ ระบบแสดงรายการแผนงานทั้งหมดของข้อมูลชุดปัจจุบัน
      2. ติ๊กช่อง ไม่รวม หน้าแผนงานที่ต้องการตัดออก — กล่องสรุปด้านล่างแสดงผลเทียบ "รวมทุกแผนงาน" กับ "ไม่รวม …" ให้ดูก่อนบันทึก
      3. กด บันทึกการตั้งค่า — Dashboard โหลดใหม่และบันทึกการเปลี่ยนแปลงลง Log
      ผลบน Dashboard: ยอดรวมเดิมทุกจุดยังแสดงตามปกติ และมีค่าเพิ่มเติม
      • แถบสรุปด้านบน — ป้าย "(กรณีไม่รวมยอด 70P05, 70P08 : แผนฯ … · เบิกจ่าย … · ผลต่ำกว่าแผน …)" ใต้ป้าย %แผนที่ตั้งไว้
      • แผงรายละเอียด — บัตรที่ 5 "ร้อยละเบิกจ่าย / แผน" พร้อมวงเล็บ (ไม่รวมยอด …) ใต้ตัวเลข แสดงเมื่อรายการย่อยมีทั้งส่วนที่ถูกตัดออกและส่วนที่เหลือ (เช่น งบ สช. ที่มีแผนงาน 70P05) — บัตรนี้ยืนยันความถูกต้องแยกได้เหมือนบัตรอื่น
      • ไม่ติ๊กแผนงานใดเลย = รวมทุกแผนงาน และไม่แสดงค่าเพิ่มเติม

      6.5ลิงก์ระบบอื่น

      ใช้จัดการเมนูในกล่อง ลิงก์ระบบอื่น ของแถบเมนูด้านซ้าย — เฉพาะ Superadmin

      1. เปิดแท็บ ลิงก์ระบบอื่น ระบบแสดงรายการเมนูทั้งหมด พร้อมตัวอย่างแถบเมนูด้านขวาที่เปลี่ยนตามทันที
      2. แก้ไขในตาราง: ชื่อเมนู, URL (ต้องขึ้นต้นด้วย https:// — เว้นว่าง = แสดงเมนูแต่แจ้งว่า "ยังไม่เปิดใช้งาน"), ไอคอน, แสดงให้ (ทุกคน / เฉพาะผู้ที่เข้าสู่ระบบ), ต่อท้ายลิงก์ (ไม่ต่อท้าย / ?user=ชื่อ-สกุล / ?user=ชื่อผู้ใช้) และช่อง แสดง (ซ่อนชั่วคราวโดยไม่ต้องลบ)
      3. ใช้ปุ่ม ▲ ▼ เพื่อเรียงลำดับ, + เพิ่มลิงก์ เพื่อเพิ่มเมนูใหม่ (สูงสุด 30 รายการ) และไอคอนถังขยะเพื่อลบ
      4. กด บันทึกลิงก์ — ผู้ใช้ทุกคนเห็นเมนูใหม่เมื่อเปิด Dashboard ครั้งถัดไป และระบบบันทึกการเปลี่ยนแปลงลง Log

      6.6ค่าตั้งระบบ (ย้ายไปบัญชี Google อื่น)

      เมื่อคัดลอกไฟล์ Google Sheets ไปบัญชีอื่น ชีตผู้ใช้ Log และข้อมูลจะติดไปด้วย แต่ค่าตั้งระบบใน Apps Script (Script Properties) ไม่ติดไป ทำให้ล็อกอินไม่ได้ (กุญแจเข้ารหัสรหัสผ่านเปลี่ยน) และลิงก์ระบบอื่น / แผนงานที่ไม่รวมคำนวณกลับเป็นค่าเริ่มต้น — ใช้แท็บ ค่าตั้งระบบ (เฉพาะ Superadmin) ย้ายค่าเหล่านี้

      1. ที่ระบบเดิม — เปิดแท็บ ค่าตั้งระบบ กรอกรหัสผ่านของตนเอง แล้วกด ดาวน์โหลดไฟล์ค่าตั้งระบบ (ได้ไฟล์ .json)
      2. ที่ระบบใหม่ — ถ้าล็อกอินไม่ได้ ให้เปิด Apps Script ของไฟล์ใหม่ เลือกฟังก์ชัน resetAdminPasswordFromEditor แล้วกด Run จากนั้นเข้าสู่ระบบด้วย admin / Admin@1234 และตั้งรหัสผ่านใหม่
      3. เปิดแท็บ ค่าตั้งระบบ › เลือกไฟล์ค่าตั้งระบบ (.json) ระบบแสดงรายการที่จะเปลี่ยน / เหมือนเดิม ให้ตรวจก่อน
      4. กรอกรหัสผ่านปัจจุบันของตนเอง แล้วกด นำเข้าค่าตั้งระบบ — ผู้ใช้คนอื่นเข้าสู่ระบบด้วยรหัสผ่านเดิมได้ทันที ส่วนผู้นำเข้าใช้รหัสผ่านปัจจุบันต่อได้
      ไฟล์ค่าตั้งระบบมีกุญแจเข้ารหัสรหัสผ่าน — เก็บไว้ในที่ปลอดภัย ห้ามส่งต่อ และลบทิ้งเมื่อย้ายระบบเสร็จ · การส่งออก/นำเข้าต้องยืนยันรหัสผ่านทุกครั้งและบันทึกลง Log · หลังย้ายแล้วต้อง Deploy เว็บแอปใหม่ (URL จะเปลี่ยน) และ Run setupAuthSystem หนึ่งครั้งเพื่ออนุญาตการส่งอีเมล OTP

      7คำถามที่พบบ่อย

      7.1ปัญหาและวิธีแก้

      อาการวิธีแก้
      ขึ้นกล่อง "เกิดข้อผิดพลาดในการโหลดข้อมูล" / การเชื่อมต่อหมดเวลามักเกิดเมื่อเปิดครั้งแรกหลังไม่มีผู้ใช้สักพัก (เซิร์ฟเวอร์ Google เริ่มทำงานช้า) — ระบบลองใหม่ให้อัตโนมัติ 1 ครั้ง ถ้ายังขึ้นให้กด ลองโหลดข้อมูลอีกครั้ง · ถ้าเปิดผ่านหน้าเว็บอื่น (เช่น github.io) หรือล็อกอิน Google หลายบัญชีในเบราว์เซอร์ ให้ลองเปิดลิงก์เว็บแอปโดยตรงหรือใช้หน้าต่างไม่ระบุตัวตน
      ย้าย/คัดลอกไฟล์ไปบัญชี Google อื่นแล้ว เปิดดูได้แต่ล็อกอินไม่ได้ค่าตั้งระบบไม่ติดไปกับไฟล์ — ส่งออกจากระบบเดิมแล้วนำเข้าที่ระบบใหม่ (หัวข้อ 6.6)
      หน้าจอมืดลง มีกล่อง "กำลัง…" และกดอะไรไม่ได้ระบบกำลังบันทึกหรือเตรียมไฟล์ดาวน์โหลด — รอจนกล่องหายไปเอง อย่าปิด รีเฟรช หรือออกจากหน้า (หากกดรีเฟรช เบราว์เซอร์จะถามยืนยันก่อน)
      หน้าจอยังแสดงข้อมูลหรือหน้าตาแบบเก่ากด Ctrl + Shift + R (Mac: Cmd + Shift + R) เพื่อโหลดหน้าใหม่
      ปีงบประมาณไม่ถูกต้องตรวจเซลล์ปีงบประมาณ (เช่น "ปีงบประมาณ 2570") ในชีตผลจำแนกตามหน่วยงาน/แผนงาน
      ตัวเลขบนจอเล็กหรือเบียดระบบปรับขนาดอัตโนมัติ ลองขยายหน้าต่าง หรือปรับระดับซูมของเบราว์เซอร์
      เข้าสู่ระบบไม่ได้ / บัญชีถูกล็อกรอ 15 นาที หรือใช้ "ลืมรหัสผ่าน" หรือติดต่อผู้ดูแลระบบ
      ไม่เห็นเมนูหลังบ้านหรือจัดการข้อมูลบัญชียังไม่ได้รับสิทธิ์ — ติดต่อ Superadmin / Admin
